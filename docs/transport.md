# Doprava

## Základné pravidlo

Japan Rail Pass sa nekupuje automaticky. Oficiálny cenník uvádza Ordinary 7 dní 50 000 JPY, 14 dní 80 000 JPY a 21 dní 100 000 JPY: https://japanrailpass.net/en/purchase/price/

Pre pracovnú trasu treba porovnať:

1. jednotlivé lístky Tokio–Kanazawa–Kjóto–Osaka,
2. regionálny pass,
3. 14-dňový celonárodný JR Pass.

## Prakticky

- používať IC kartu Suica/PASMO/ICOCA na metro a mestské vlaky,
- shinkansen rezervovať pre 5 ľudí naraz,
- pri ubytovaní kontrolovať vzdialenosť od stanice, nie iba názov štvrte,
- pri starších cestujúcich uprednostniť menej prestupov pred najnižšou cenou,
- batožina je iba príručná, takže netreba riešiť takuhaibin; napriek tomu treba mať miesto na pohodlný presun.

## Presuny v itinerári

| Úsek | Odporúčanie |
|---|---|
| letisko → Tokio | podľa príletu HND/NRT; vybrať ubytovanie podľa stanice |
| Tokio → Nikko/Kamakura | samostatný denný lístok alebo regionálna kombinácia |
| Tokio → Kanazawa | Hokuriku Shinkansen |
| Kanazawa → Kjóto | Limited Express + shinkansen podľa aktuálneho cestovného poriadku |
| Kjóto → Nara | JR alebo Kintetsu |
| Kjóto → Osaka | miestny vlak, JR alebo Hankyu podľa polohy hotela |
| Osaka → Himeji | JR alebo shinkansen podľa rozpočtu |
| Osaka → KIX | Nankai alebo JR podľa terminálu |
